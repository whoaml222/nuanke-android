# 随记使用说明

## 打开与书写

- 底部「随记」或「今天」页的小入口可打开日记；设置现在位于主页面右上角齿轮。
- 首次使用前，请给手机设置锁屏密码。每次进入随记，用系统指纹或锁屏凭据验证；暖刻不会获取密码或指纹数据。
- 点击「写一篇」。标题、心情和标签都可不填，一天可以写多篇，也可以点击日期补写。
- 正文最多 10 万字符，总文字容量约 400 万字符；长文在输入框内滚动。输入后自动保存，等到「已保存到本机」再结束。保存失败时不要清除数据或强制停止，检查空间并点击错误提示重试。
- 「插入今日专注记录」只插入当时的统计文字，之后不会随统计变化，也不会自动评价你的表现。

## 照片与隐私

- 每篇最多 6 张照片，通过系统选择器主动选择，不授予整个相册的访问权限。
- 日记保存的是最长边不超过 1600 像素的 JPEG 副本，会移除 EXIF/定位信息；透明或动态图像会转为静态 JPEG。原相册照片不变。
- 离开页面、切后台或重新创建页面后需要再次验证。选择照片/文件后若页面曾进入后台，也需要重新验证。
- 日记页禁止截图和录屏/投屏，最近任务预览应被遮挡。手机投屏时显示黑色或空白可能是隐私保护，而不是闪退；不同系统的实际表现需要真机确认。
- 日记及照片在本机加密保存，不上传 GitHub，不进入诊断报告。设备已被攻破或不可信输入法不在此应用锁的保护范围内。

## 回看与删除

- 左右箭头切换月份，点击年月选择具体日期；搜索会跨日期查找正文、标题、心情和标签。
- 删除先移入回收站，30 天内可以恢复；永久删除会再次确认。超过 30 天的记录在下次打开随记时清理，没有后台清理任务。
- 只删除日记中的照片副本，不删除相册原图。逻辑删除不等于可保证的取证级擦除。

## 备份与换手机

1. 随记列表中的「⋯」打开备份与隐私，选择「创建加密备份」。
2. 选择文件位置，重新验证后设置 8–128 字符的独立备份密码并确认；建议使用较长密码。
3. 文件扩展名为 `.nkdiary`，包含文字、照片及回收站。单个备份上限 64 MiB；未完成或失败的文件不能用于恢复。
4. 新手机安装暖刻并设置手机锁屏密码后，通过「恢复加密备份」选择文件、输入原备份密码即可。
5. 恢复只添加当前不存在的日记，相同 ID 的本机记录不被覆盖，重复导入不会生成重复日记。

备份密码无法找回。请先备份再卸载、清除数据或换手机；系统自动备份/设备迁移不会替你备份日记。文件选择器中若选择了云盘，表示你主动把加密备份交给该服务保存。

使用系统接口：[照片选择器](https://developer.android.com/training/data-storage/shared/photo-picker)、[系统身份验证](https://developer.android.com/reference/android/hardware/biometrics/BiometricPrompt)。
