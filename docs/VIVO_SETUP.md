# vivo Android 16 setup

首次使用需要你在系统设置中完成一项授权：

1. 辅助功能中的“暖刻应用守护”：用于实时识别前台应用包名、显示提醒和返回桌面。配置明确禁止读取窗口内容。连续时长与每日累计都由这项本地计时完成，因此不需要额外授予“使用情况访问权限”。

如果系统长时间后停止服务，可在 vivo 的电池/后台管理中允许暖刻后台运行。不要授予设备管理员权限；暖刻不需要该权限。

紧急恢复方法：在系统“辅助功能”中关闭“暖刻应用守护”，所有拦截会立即停止。无需恢复出厂设置。

## 开启后立刻关闭 / 到时没有提醒

先覆盖安装最新修复版，不要卸载或清除应用数据（会丢失本机规则与记录）。安装后打开暖刻，到辅助功能重新开启一次，然后返回暖刻的“设置”。

- “系统开关未开启”：系统没有保留授权，当前不能计时或拦截。
- “系统已授权，但守护服务未连接”：授权记录存在，但服务并没有运行；不能只凭开关判断正常。
- “守护运行中”：服务已连接并成功读入规则。

如果仍会自动关闭，点“复制本机诊断”并手动发送给开发者。报告只包含暖刻自身的连接事件、异常类型/代码位置、系统进程退出原因码，不包含聊天、屏幕内容或所选应用清单；不会自动上传。它能帮助区分应用异常和系统停止进程，不能代替现场日志保证判断所有厂商行为。

可在 vivo 系统的应用/电池管理中检查暖刻的自启动和后台运行设置，具体入口随系统版本不同。不要为此恢复出厂设置、root、授予设备管理员或关闭手机整体安全保护。暖刻不会自行修改无障碍授权。

验证限制时，可给一个视频应用设为连续 1 分钟、每日 60 分钟、冷静 1 分钟，保持亮屏使用至提醒出现。重复窗口事件不应累加次数；离开再进入算新的一次。锁屏不计应用用时，冷静结束后应恢复可用（若每日上限或专注限制仍生效则继续拦截）。
